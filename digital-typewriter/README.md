# Digital Typewriter - آلة كاتبة رقمية

تطبيق آلة كاتبة رقمية مستقل يدعم العربية والإنجليزية، يعمل على Fedora 44 مع GNOME وWayland.

![Digital Typewriter](assets/screenshot.png)

## الميزات

- ✍️ محرر نصوص متعدد الأسطر مع دعم Unicode الكامل
- ⌨️ لوحة مفاتيح رقمية مدمجة بتخطيط UK English
- 🇸🇦 دعم كامل للغة العربية مع اتجاه RTL
- 🔄 تبديل سريع بين اللغتين EN/العربية
- 📋 نسخ النص إلى الحافظة
- 🗑️ مسح النص مع تأكيد
- 📐 تصميم متجاوب يتكيف مع حجم النافذة
- 🎨 تصميم مستوحى من الآلة الكاتبة الكلاسيكية
- 🖱️ دعم الكتابة بالماوس ولوحة المفاتيح الفيزيائية
- 🖥️ متوافق مع Wayland و GNOME

## المتطلبات

- Fedora 44
- GNOME 44+
- Wayland
- Python 3.11+
- GTK 4
- LibAdwaita
